Welcome!

This learning hub introduces Docker and the technologies used to build, run, and deploy containerized applications. Explore the topics and save your own notes below.

1. Docker

Docker packages an application and its dependencies into an image. A container is a running instance of that image.

  • Image: A template used to create containers.
  • Container: An isolated running environment.
  • Dockerfile: Instructions for building an image.
  • Volume: Storage that can persist beyond a container's lifetime.
  • Port mapping: Makes a container service accessible from the host.

2. Docker Compose

Docker Compose defines and manages multi-container applications using a YAML configuration file.

Services, networks, volumes, and environment variables can be described in one place and started together. 

docker compose up --build
docker compose ps
docker compose down

3. Microservices

A microservice architecture divides an application into smaller services with clearly defined responsibilities. Services communicate through interfaces such as HTTP APIs.

Containers can make services easier to package and deploy independently. However, using Docker alone does not automatically make an application a microservice system.
