⚙️ What Is Docker Compose?

Docker Compose is a tool for defining and running applications that consist of multiple containers. Instead of starting each container manually, we describe the services in a YAML file named compose.yaml.

Compose can configure image builds, ports, environment variables, networks, storage, dependencies, and health checks in one place.

The Three Services

1. Web

The web service runs a Flask application using Gunicorn. It serves the website and sends requests to the API. Port 5001 on the host is mapped to port 5000 in the container.

2. API

The API provides HTTP endpoints for retrieving and saving notes. It receives requests from the web service and communicates with PostgreSQL.

3. Database

The database service uses PostgreSQL to store notes. A named Docker volume keeps database data persistent across ordinary container replacements.

Example from compose.yaml

This simplified example shows how the web service connects to the API and how the API depends on the database. The full configuration contains additional settings. 

services:
  web:
    build: .
    ports:
      - "5001:5000"
    environment:
      API_HOST: api
      API_PORT: "5000"
    depends_on:
      api:
        condition: service_started

  api:
    build:
      context: .
      dockerfile: api/Dockerfile
    environment:
      DB_HOST: db
      DB_NAME: learninghub
      DB_USER: learninguser
      DB_PASSWORD: ${DB_PASSWORD}
    depends_on:
      db:
        condition: service_healthy

  db:
    image: postgres:16-alpine
    volumes:
      - postgres-data:/var/lib/postgresql/data

volumes:
  postgres-data:

Environment variables allow services to receive configuration without hardcoding it in the application source. The database password is stored in a local .env file, which should not be committed to Git.

Useful Docker Compose Commands

# Validate and render the Compose configuration
docker compose config

# Build images and start all services
docker compose up --build

# List services and their status
docker compose ps

# Follow service logs
docker compose logs -f

# Stop and remove project containers and network
docker compose down

The docker compose up --build command builds the required images and starts the services. Compose also creates the project network so services can communicate using their service names, such as api and db.

The docker compose down command does not normally delete named volumes. Avoid adding -v when you want to preserve your database data.

Why Use Docker Compose?

  • All services are described in one configuration file.
  • The environment is easier to reproduce on another computer.
  • Services can communicate through a project network.
  • Persistent storage can be configured alongside the services.
  • Configuration changes can be version-controlled with the project.
